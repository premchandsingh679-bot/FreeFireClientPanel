## 🐛 Troubleshooting

### ❌ Installation blocked
**Solution:**
- Settings → Security → Unknown Sources → Enable
- Or Settings → Apps → Special App Access → Install Unknown Apps → Allow from Downloads

### ❌ App crashes on startup
**Solution:**
- Uninstall and reinstall
- Clear app cache: Settings → Apps → Free Fire Client → Storage → Clear Cache
- Ensure Android 6.0 or higher

### ❌ Floating panel not showing
**Solution:**
- Check overlay permission: Settings → Apps → Free Fire Client → Display over other apps → Allow
- Restart app
- Restart phone

### ❌ Notifications not working
**Solution:**
- Enable in app settings
- Check system notifications: Settings → Notifications → Free Fire Client → Allow
- Android 8.0+ required for notifications
